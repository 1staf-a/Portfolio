Large Deflections in a Cantilever

When a beam fixed at one end bends substantially, its changing shape affects how it carries the load. A Python solver models that response under different loads.

  • Python
  • Numerical Methods
  • Rod Mechanics

Mechanical model and solver

Developed a nonlinear elasticity model for slender beams and rods and implemented a custom Python solver. Analyzed the response of a cantilever under varying loads while retaining geometric nonlinearity, which accounts for how the deformed geometry changes the mechanical response.
