Flow Simulations for Design Comparisons

Built a repeatable workflow at NaqCoDE Technologies to see how design changes affected predicted flow and give engineers a consistent basis for comparing designs.

  • ANSYS Fluent
  • CFD
  • Post-processing

Geometry and simulation setup

Prepared complex computer-aided design (CAD) geometry for computational fluid dynamics (CFD) studies in ANSYS Fluent. Set up parametric simulations to evaluate how changes to the design affected the predicted flow.

Post-processing and design decisions

Standardized how simulation data were stored and post-processed so cases could be compared consistently. Analyzed sensitivity to design changes, documented numerical results and modeling limitations in technical reports, and trained interns to use the team’s simulation workflows.
